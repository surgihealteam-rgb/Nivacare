## GitHub Pages

1. Create a new GitHub repository, e.g. `niva-care`.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. GitHub will provide the public URL.

## Important before launch

Replace or add the following as the business becomes operational:
- Legal entity name
- Registered address
- Privacy Policy
- Terms of Service
- Healthcare/provider licensing and registration details applicable to Telangana
- Actual provider verification claims only after the checks are completed
- Final service prices and coverage areas
- Real business email
- Google Business Profile / social links

The enquiry form opens WhatsApp directly; no server/database is required.
