# NIVA CARE — GitHub-ready website

**Tagline:** Every Day, A New Beginning.

A responsive, mobile-first static website for NIVA CARE. The site uses an original visual direction inspired by common premium home-healthcare UX patterns: strong hero CTA, service discovery, care journey, trust section, family stories, FAQ and callback form.

## Contact number
**6300695591** is wired into call buttons, WhatsApp buttons and the enquiry form.

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`.
5. Save. GitHub will publish the site.

## Important before launch
- Replace illustrative testimonials with verified patient feedback.
- Confirm the exact service scope, geography, pricing, availability and clinical claims.
- The photography currently uses external Unsplash image URLs for a lightweight GitHub-ready demo. For a fully self-contained production site, replace them with properly licensed/local NIVA CARE photography.
- Connect the enquiry form to your CRM, email, WhatsApp automation or backend when ready.
